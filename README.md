# Silo Flex Brilliance

Crie uma landing page profissional, moderna, premium e altamente persuasiva para a empresa **SILO FLEX - Sacos para Silagem**, utilizando exclusivamente as informações, logo e imagens fornecidas como base visual e comercial.

A landing page deve transmitir **força, confiança, qualidade, sustentabilidade e experiência no segmento agropecuário**, com uma estética moderna e profissional.

## IDENTIDADE VISUAL

A cor predominante da página deve ser **verde**, inspirada diretamente no logo da Silo Flex e nas embalagens apresentadas nas imagens.

Utilize uma paleta sofisticada com:

* verde escuro institucional;
* verde médio;
* verde mais claro para destaques;
* branco;
* off-white;
* pequenos detalhes em tons neutros.

O verde deve aparecer em botões, títulos estratégicos, fundos de seções, elementos gráficos e detalhes da interface.

Evite um design genérico de empresa agrícola. A página deve parecer uma marca profissional, consolidada e especializada.

Use bastante espaço em branco, tipografia moderna, elementos com cantos levemente arredondados, sombras suaves e uma composição visual limpa.

## REFERÊNCIA DE ESTRUTURA

Use o site https://siloplast.com.br/ como **referência de estrutura, organização e experiência**, principalmente na forma de apresentar produtos, benefícios, diferenciais, chamadas para orçamento e informações institucionais.

A página deve ter ritmo visual semelhante a uma landing page comercial moderna, com seções alternando entre fundos claros e verdes.
